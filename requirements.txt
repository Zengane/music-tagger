# torch/torchvision/torchaudio are pinned to the CUDA 13.0 build on purpose.
#
# v1 died here: `muq` depends on x_clip, which depends on torchvision, and pip's
# resolver happily swapped the CUDA torch for a CPU wheel off PyPI. Everything
# still ran, just ~40x slower, on the CPU. Pinning the +cu130 local version
# means pip refuses to substitute a CPU build instead of doing it silently.
